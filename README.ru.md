# Umiio Q1 после OTA — белый экран, Wi-Fi и восстановление Keystone

[English](README.md) · [Release notes](RELEASE_NOTES.md) · [Сборка](docs/BUILD.md) · [Credits](CREDITS.md)

Если после штатного обновления Umiio Q1 появился белый экран, пропали настройки Wi-Fi/Keystone или проектор кажется полукирпичом — не спешите прошивать или делать factory reset. На одном Q1 удалось восстановить launcher, Wi-Fi и полный Keystone без root и перепрошивки.

**Неофициальный способ восстановления, не прошивка и не универсальный фикс. Проверено владельцем на его Umiio Q1 с Android 9. Q2, другие Umiio и другие ревизии Q1 не проверены.** Одинаковые симптомы не доказывают совместимость железа, системных пакетов и координат.

## Что реально проверено

| Результат | Основание / ограничение |
|---|---|
| После OTA Android работает, хотя штатный интерфейс частично сломан | Подтверждено в процессе восстановления этого Q1 |
| Рабочий домашний экран через Projectivy Launcher | Подтверждено владельцем |
| Wi-Fi через Repair Control / WifiManager, без TvSettings | Подтверждено с предыдущей версией helper на этом Q1 |
| Keystone через главное меню ProjectionSettings | Владелец подтвердил движение наружу и восстановление полного прямоугольника |
| Итоговые координаты ниже | Подтверждены read-back и визуальным результатом владельца |
| Очищенный APK 2.0.0 | Локальные проверки описаны в [VALIDATION.md](docs/VALIDATION.md); на Q1 пока не запускался |
| Q2 / другой Q1 или другая OTA-сборка | **Не проверено** |

Это обход повреждённого интерфейса и ошибки инициализации, а не починка всех системных компонентов Android. Точный первичный дефект всей OTA не установлен. Старый прямой запуск ручного Keystone из нашего helper также создавал отдельную проблему — в финальном приложении этот путь удалён.

## What actually fixed Keystone — что действительно помогло

```text
Wrong:   launcher / старый RepairControl → direct KeystoneActivity
Correct: ProjectionSettings MainActivity → Keystone menu → KeystoneActivity
```

Открывать нужно:

```text
com.telanda.keystone.MainActivity
```

**Не создавайте прямой ярлык на `com.telanda.keystone.KeystoneActivity`.**

В изученном OEM-коде главное меню инициализирует размеры экрана до того, как helper ручной коррекции кэширует границы. Прямой вход в ручную Activity в свежем процессе может пропустить эту инициализацию. `raw=1000` сам по себе её не исправляет. После правильного входа на этом Q1 углы снова пошли наружу. [Техническое объяснение](docs/KEYSTONE.md).

Если ручную Activity уже открывали напрямую, выполните **обычную полную перезагрузку**, затем первым откройте главное меню ProjectionSettings. Режим ожидания и кнопка Back не гарантируют новый процесс. Не очищайте данные приложения и не повторяйте reset.

## Порядок восстановления

### 1. Вернуть рабочий launcher

Если доступен магазин, файловый менеджер или другой launcher, установите/откройте Projectivy из официального источника:

- [Projectivy в Google Play](https://play.google.com/store/apps/details?id=com.spocky.projengmenu)
- [Официальные GitHub Releases разработчика](https://github.com/spocky/miproja1/releases)

Настройте домашний экран штатными средствами Projectivy. Не удаляйте и не отключайте системные пакеты. Инженерные и калибровочные функции других приложений в этот способ не входят.

Если остался только белый экран, но проектор доступен с телефона, первоначальный способ через Android TV remote и магазин описал **mopen_popen**: [«Белый экран после обновления проектора Umiio Q1»](https://otvet.mail.ru/question/269073066). Для него требуется возможность связаться с проектором; это не гарантированный offline-способ. Авторство первоначального выхода из белого экрана принадлежит mopen_popen.

Если Android не загружается либо невозможно открыть/установить приложение, наш APK сам себя не установит. Не переходите вслепую к чужим прошивкам и заводским меню.

### 2. Установить Repair Control

Загрузка — [GitHub Releases этого проекта](https://github.com/JacSoul/umiio-q1-ota-recovery/releases). Используйте APK и соответствующий `SHA256SUMS.txt` из одного релиза. **Первый APK 2.0.0 публикуется как pre-release: локальные проверки пройдены, на Q1 эта сборка ещё не запускалась.** Сам способ восстановления подтверждён владельцем Q1 с предыдущими инструментами.

Передайте `UmiioQ1RepairControl.apk` через работающий файловый менеджер, сеть либо обычную флешку и подтвердите стандартную установку Android. Это установка приложения, не загрузочный USB и не обновление прошивки. Форматировать накопитель не нужно.

Проверка SHA-256 в Windows:

```powershell
Get-FileHash .\UmiioQ1RepairControl.apk -Algorithm SHA256
```

Версия 2.0.0 сохраняет пакет `local.umiioq1.repaircontrol`, прежнюю локальную подпись и повышает versionCode. При конфликте подписи остановитесь: системные приложения удалять нельзя. Самостоятельная сборка с другим ключом не обновит предоставленный helper поверх существующей установки.

### 3. Подключить Wi-Fi без TvSettings

1. Введите **свой** точный SSID и пароль. Персональных сетей в APK нет.
2. Выберите WPA/WPA2 Personal либо явно открытую сеть. WPA3-only и Enterprise helper не поддерживает. При неизвестной поддержке 5 GHz используйте 2.4 GHz.
3. Для проверки SSID Android 9 запрашивает Location permission. Приложение не получает GPS-координаты. Если Android скрывает SSID, может потребоваться включённая геолокация через доступный штатный интерфейс.
4. Нажмите **«Подключить Wi-Fi — показать план»**, прочитайте изменения и подтвердите.
5. Дождитесь совпадения SSID, ненулевого IPv4 и события `NETWORK_STATE_CHANGED_ACTION`. Один лишь успешный вызов `reconnect()` подключение не доказывает.

Используется WifiManager: добавить/обновить конфигурацию одного SSID → проверить networkId → сохранить → выбрать сеть → reconnect. Предыдущая сеть может отключиться. При ошибке сохранённая конфигурация может остаться; автоматического отката и повторных попыток нет. Кнопка подключения намеренно работает только на Android 9/API 28.

Пароль получает Android и сохраняет в своей конфигурации Wi-Fi. Repair Control не пишет его в собственные файлы/логи и очищает поле. TvSettings, NetworkActivity, EthernetManager, ADB и reset проекции не используются. [Разрешения и приватность](docs/PRIVACY.md).

IPv4 не гарантирует интернет. Client isolation может мешать устройствам видеть друг друга при работающем интернете; локальная точка доступа — альтернативная сеть, а не обязательный этап ремонта. ADB для этого способа не нужен.

### 4. Восстановить геометрию

1. Если уже открывали Keystone напрямую, сначала обычная полная перезагрузка. **MENU Reset не нажимайте.**
2. Нажмите **Open Projection Settings**. Открывается только `com.telanda.keystone.MainActivity`.
3. Если Zoom уже `raw=1000`, не меняйте его. Иначе аккуратно восстановите Zoom через штатный пункт **Quick move / Zoom**: на проверенном Q1 RIGHT увеличивал изображение. Проверьте `raw=1000` и вернитесь в главное меню ProjectionSettings. Не переносите это направление вслепую на другую прошивку.
4. Выберите **Keystone внутри главного меню**. Настройте углы вручную. В изученном Q1 OK переключает LT → RT → RB → LB. Наружу: LT ←/↑, RT →/↑, RB →/↓, LB ←/↓. Угол, уже дошедший до границы, дальше двигаться не должен.
5. Вернитесь в Repair Control, обновите read-only статус и проверьте саму картинку. Не продолжайте двигать углы внутрь, пытаясь увеличить изображение.

Если координаты выходят за диапазон, кнопки ведут себя иначе, главного меню нет либо движение наружу остаётся заблокированным после правильного входа — остановитесь, не подбирайте дополнительные изменения вслепую. В helper нет автоматического reset.

### Контрольное состояние — только проверенный Q1

```text
Zoom: 100%
scale=1.000
raw=1000

LT=0,600
RT=1024,600
LB=0,0
RB=1024,0

Geometry: FULL RECTANGLE
```

`scale` вычисляется как `raw/1000`, а не измеряется независимо. `Geometry` сравнивает прочитанные углы с размером OEM canvas; `Q1 reference: MATCH` дополнительно требует 1024×600 и raw=1000. Цифры не заменяют визуальную проверку. Полный цифровой прямоугольник не исправляет положение проектора и оптический фокус.

## Чего НЕ делать

- **MENU Reset** в ручном Keystone этой проблемной OTA — при восстановлении он оказался ненадёжным/небезопасным.
- Прямой ярлык `KeystoneActivity` и старую кнопку **Open Manual Keystone**.
- `Auto_set_zero`, FactoryMode, инженерную калибровку, factory reset.
- Root, ADB/JDWP, прямую запись vendor-properties, OTA/firmware rollback и flashing.
- Замену/удаление системных APK и эксперименты с их подписью.

Старые экспериментальные collectors/exporters и PC repair kits **не нужны**. Bluetooth намеренно отложен.

## Troubleshooting

| Проблема | Безопасное действие |
|---|---|
| Белый экран, но пульт на телефоне видит Q1 | Способ из поста mopen_popen; launcher из официального источника |
| Главное Projection Settings отсутствует/падает | Остановиться: для этой сборки способ не подтверждён |
| Наружу не двигается после прямого ярлыка | Полная обычная перезагрузка, первым главное меню; без MENU Reset |
| Zoom 100%, изображение всё ещё маленькое | Zoom и границы углов — разные состояния; правильный вход и проверка углов |
| Properties = `UNKNOWN` | Прошивка может запрещать чтение; неизвестное не означает ноль или успех |
| SSID скрыт / подключение не подтверждено | Проверить разрешение, доступность геолокации, SSID и тип сети |
| `addNetwork/updateNetwork = -1` | Система отвергла конфигурацию/доступ; не менять Keystone |
| Интернет есть, устройства друг друга не видят | Проверить client isolation; ADB этому решению не требуется |
| Координаты правильные, картинка нет | Проверить оптику/установку; не считать числовое совпадение финальным успехом |
| Q2 или другой Umiio | Не проверено; не навязывать другой модели координаты Q1 |

## Если вы искали решение для Umiio Q2

Похожие случаи белого экрана/сломанных настроек после OTA встречаются для Q2, но здесь описано **восстановление одного Q1**. Проверенного исправления прошивки Q2 этот проект не предлагает. Сравнивайте модель и сборку; не записывайте координаты Q1 на другую матрицу.

## Как безопасно сообщить о результате

В [GitHub Issues](https://github.com/JacSoul/umiio-q1-ota-recovery/issues) можно указать модель, версию Android, симптомы и что помогло. Не публикуйте пароль, SSID, IP/MAC, серийный номер, неотредактированные фотографии или полные диагностические коллекции. Инструкция посвящена запросам «Umiio Q1 белый экран после обновления», «не работают настройки Wi-Fi», «Keystone не двигается наружу», «маленькое изображение при Zoom 100%».
